Aula 1: Introdução e Fundamentos do Android

Uma jornada interativa pela história, arquitetura e futuro do Android.

Resumo em Áudio da Aula

Objetivo Geral:

Capacitar o aluno para projetar, implementar e testar aplicações móveis nativas e híbridas, compreendendo boas práticas de persistência local, consumo de APIs e integração com serviços backend modernos.

Objetivos Específicos:

  • Criar interfaces e controlar a navegação em apps Android com Kotlin.
  • Implementar persistência local com SharedPreferences e Room.
  • Consumir APIs RESTful com Retrofit e corrotinas.
  • Integrar funcionalidades com Firebase (Firestore e Autenticação).
  • Aplicar boas práticas com ViewModel e LiveData.
  • Compreender os fundamentos do desenvolvimento híbrido com React Native.

Por que Aprender Android com Kotlin?

✓ Mais Seguro

Ajuda a evitar `NullPointerException`, o erro mais comum em Java, graças ao seu sistema de tipos robusto.

✎ Mais Conciso

Escreva significativamente menos código para as mesmas tarefas. Menos código, menos bugs.

↔ 100% Interoperável

Use código Kotlin e Java no mesmo projeto sem problemas. Aproveite bibliotecas Java existentes.

⚡ Corrotinas

Suporte nativo e simplificado para programação assíncrona, essencial para apps modernos e responsivos.
